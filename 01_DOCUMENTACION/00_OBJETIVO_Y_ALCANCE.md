# Sistema de Gestión Integral

## Objetivo

Desarrollar un sistema modular para gestionar integralmente los procesos
administrativos, operativos y productivos de una empresa.

## MVP

La primera versión operativa incluirá:

- Usuarios
- Roles y permisos
- Artículos
- Almacenes
- Inventario
- Movimientos
- Proveedores
- Compras básicas
- Recepción de materiales
- Dashboard
- Auditoría y trazabilidad

## Dedicación

3 horas diarias aproximadamente.

## Objetivo del MVP

Construir una primera versión funcional, estable y escalable sobre la cual
se puedan desarrollar posteriormente nuevos módulos.

## Principio

El sistema será modular y permitirá incorporar nuevas funcionalidades
sin tener que reconstruir el sistema completo.
