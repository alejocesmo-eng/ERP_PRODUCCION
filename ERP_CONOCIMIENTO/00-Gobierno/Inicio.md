# Sistema de Gestión Integral — Centro de conocimiento

## Propósito
Este vault conserva el conocimiento empresarial y las decisiones que orientan el desarrollo del ERP.

## Reglas
- Distinguir borrador, propuesto, aprobado y obsoleto.
- Toda regla de negocio importante debe tener fuente, responsable o pregunta pendiente.
- No guardar contraseñas, tokens, secretos ni datos personales innecesarios.
- No duplicar el código ni tratar las notas como prueba de que una función ya existe.
- Las decisiones aprobadas deben registrar fecha, responsable y motivo.
