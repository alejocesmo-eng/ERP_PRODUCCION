# Skill: Obsidian Flavored Markdown

- **YAML Frontmatter**: Debe ir estrictamente en las primeras líneas del archivo delimitado por `---`.
- **Wikilinks**: Utiliza la sintaxis `[[Nombre Nota]]` para vincular documentos internos.
- **Callouts**: Utiliza la sintaxis `> [!NOTE]` o `> [!WARNING]` para resaltar información clave.
- **Formato Estricto**: Respeta los metadatos y la estructura de carpetas de `ERP-CONOCIMIENTO/`.
